How your board boots, and how much of it you'll replace

Power on
  │
  ▼
BootROM ── built into the chip, can't be changed. Looks for SD/flash; if nothing → MaskROM (USB)
  │
  ▼
idblock.img ── DDR init (Rockchip's closed binary) + SPL. Turns on the 64 MB of RAM.
  │
  ▼
uboot.img ──── U-Boot: console, SD driver, loads the kernel into RAM, passes it the device tree
  │
  ▼
boot.img ───── Linux kernel + device tree    ◄── YOU REPLACE THIS
  │
  ▼
rootfs.img ─── init → getty → login → shell  ◄── LATER, YOUR OWN USERSPACE

SD card layout (from sd_update.txt, in 512-byte sectors): env @ 0x0, idblock @ 0x40, uboot @ 0x440, boot @ 0x640, oem @ 0x10640, userdata @ 0x110640, rootfs @ 0x190640.
